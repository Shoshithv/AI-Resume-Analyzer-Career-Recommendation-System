# AI-Resume-Analyzer-Career-Recommendation-System

## 1. Project Description

The AI Resume Analyzer & Career Recommendation System is a web-based application designed to help university students, fresh graduates, and job seekers improve their resumes and explore suitable career opportunities.

Users will be able to upload their resumes in PDF format. The system will extract important information such as education, skills, projects, and work experience. It will analyze the resume, identify strengths and weaknesses, highlight missing skills, and suggest suitable career paths based on the user's qualifications and skills.
